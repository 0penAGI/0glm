# granular-brain v3 — one-file semantic navigator

Микро-мозг на гранулах: связные ответы из осцилляторного поля, **весь knowledge запечён в один файл** (1.9 GB), на инференсе — ноль ретрива, ноль внешних индексов.

## Что это

- Корпус дробится на «зёрна» (grains) трёх уровней: микро (предложения-мысли), мезо (абзацы), макро (документы).
- Каждое зерно → семантический вектор (MiniLM 384d) + позиция в пуле.
- Планировщик — трансформер над состоянием поля осцилляторов: вопрос подаётся как **отдельный qsem-токен**, поле шаг за шагом предсказывает эмбеддинг следующего зерна; снап к ближайшему запечённому зерну = следующий фрагмент ответа.
- Артефакт `brain.pt` = веса планировщика + банк зёрен + doc-embs + маски качества. Один файл. Грузится за ~10 c.

## Как учили

| Этап | Что добавлено |

| v16 | базовый planner: NCE по семам + аффект |
| v17–v18 | целые зёрна вместо огрызков; смешанные негативы (75% кластерных + 25% глобальных) |

| v21/v3 | ×3 демо (53K), **док-дискриминативные негативы**: «продолжай линию этого дока, не парафраз из соседнего» |

## Честные результаты (слепое голосование хозяйки, ride = учитель)

| Серия | Мозг : ride | Комментарий |
|---|---|---|
| brain_v0 | 0 : 5 | поведение не запечено, только знания |
| brain_v4 | 0 : 5 | дрейф + синдикат-коллажи |
| brain_v2 (дистилляция) | **2 : 3** | выигрывает dict и El Niño |
| brain_v3 (док-негативы) | **2 : 3** | те же проигрывающие пары |

Сюит (rel/recall, детерминированный rollout):

```
ocean    rel=.68 recall=.65     sleep   rel=.57 recall=.59
dict     rel=.50 recall=.62     ElNiño  rel=.71 recall=.61
BH       rel=.30 recall=.56
```

Удержание вопроса pred·q по ходу ответа: .41 старт → .37 финиш, ровно (до дистилляции распадалось .24→.10).

## Известное ограничение (архитектурное, не баг)

Планировщик **локален**: выбирает следующее зерно из (контекст, вопрос). Учитель знает заранее, что 20 зёрен одного дока образуют связный абзац — связность у него бесплатная. Поэтому мозг выигрывает на сборке из нескольких точек (El Niño) и тонком корпусе (dict), проигрывает там, где нужен один длинный авторский кусок (BH, сон, океан).

План v7: план-токен уровня документа — якорь выбирается один раз, навигация внутри дока амортизируется из демо. Структурный аналог арки учителя в весах.

## Файлы

- `granular_text_field.py` — ядро: пул, семантика, поле, канонизация, запекание
- `brain_chat.py` — череп-протокол инференса (рабочая память + форматирование)
- `gen_demos.py`, `bake_train_v4.py`, `bake_brain.py` — пайплайн демо→тренировка→артефакт
- `eval_brain.py`, `forensics_bake.py` — замер и вскрытие поля

## Данные

Веса натренированы на локальном исследовательском корпусе веб-текстов (~12.7K документов, 1.27M зёрен). Корпус **не распространяется**; в репозитории код пайплайна — корпус и веса воспроизводятся из своих данных.

## Запуск

```bash
pip install -r ../requirements.txt
python brain_chat.py --brain checkpoints/brain_v3.pt --ask "What causes El Nino?"
```
